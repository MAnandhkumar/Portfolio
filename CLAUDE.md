# Portfolio Development Rules & Commands

## Commands

- **Local Dev Server**: `npm run dev` (Runs on Webpack dev server to avoid Windows path-with-space/Antivirus Turbopack compilation errors)
- **Production Build**: `npm run build`
- **Linting & Code Quality**: `npm run lint`
- **TypeScript Checking**: `npm run typecheck`
- **Auto-Formatting**: `npm run format`
- **Testing**: `npm run test` (Runs standard Jest suite)
- **Test Coverage**: `npm run test:cov` (Runs Jest coverage with text-summary to keep terminal clean. Targets: >95% lines, >90% branches)
